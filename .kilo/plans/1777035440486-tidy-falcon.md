# Plan: Create New Employee Report API for Flexible Date Ranges

## Goal
Create a new API endpoint to generate comprehensive employee reports for flexible date ranges (1 week, several days, 3 months, any date range).

## Analysis of Existing System
The HRMS backend already has a robust attendance reporting system:
- Endpoints under `/attendance/reports/` support date range queries
- Services and repositories handle date range processing
- Biometric endpoints provide detailed punch data
- Timesheet and overtime services exist
- Proper authentication and authorization middleware is in place

However, there isn't a single endpoint that provides a comprehensive employee report combining all relevant data (attendance, timesheets, overtime, leave) for a given date range.

## Proposed Solution
Create a new endpoint: `GET /api/v1/attendance/reports/employee-comprehensive`

### Features
- Accepts required `start_date` and `end_date` parameters (YYYY-MM-DD format)
- Optional filters: `employee_id`, `department_id`, `location_id`
- Returns comprehensive report per employee including:
  - Attendance summary (present/absent/late rates)
  - Timesheet hours (regular, overtime, billable)
  - Leave information
  - Overtime details
  - Compliance violations
- Secured with HR/Admin authentication
- Follows existing API patterns and response formats
- Includes proper validation and error handling

## Endpoint Details

### `GET /api/v1/attendance/reports/employee-comprehensive`

#### Authentication & Authorization
- **Auth:** `AuthMiddleware()`
- **Permissions:** `HRMiddleware()`

#### Query Parameters
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `start_date` | string | Yes | Start date (YYYY-MM-DD) |
| `end_date` | string | Yes | End date (YYYY-MM-DD) |
| `employee_id` | uint | No | Filter by specific employee |
| `department_id` | uint | No | Filter by department |
| `location_id` | uint | No | Filter by location |
| `page` | int | No | Page number (default: 1) |
| `page_size` | int | No | Items per page (default: 20, max: 100) |

#### Validation Rules
- `start_date` and `end_date` must be in YYYY-MM-DD format
- `start_date` must be before or equal to `end_date`
- Maximum date range: 365 days (1 year) to prevent performance issues
- `page_size` must be between 1 and 100

#### Response Structure
Per-employee comprehensive report containing:
1. **Employee Info:** ID, name, department, position
2. **Period:** start_date, end_date
3. **Attendance:** working days, present, absent, late, early departure, present %
4. **Timesheet:** total hours, regular, overtime, billable, non-billable
5. **Leave:** total days, leave types breakdown, pending/approved
6. **Overtime:** total requests, approved/pending/rejected hours
7. **Compliance:** violations count and details

#### Error Responses
- `400 Bad Request` - Invalid date format, reversed dates, or exceeded max range
- `401 Unauthorized` - Not authenticated
- `403 Forbidden` - Not HR/Admin user
- `404 Not Found` - No employees found for given filters
- `500 Internal Server Error` - Database or processing error
